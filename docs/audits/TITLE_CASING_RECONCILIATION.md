## Decisions and protected content

No unresolved heading casing decisions remain. Ambiguous single-word labels are accepted as sentence-compatible. Proper names explain unchanged Add Classic, Next Classics, Eligible Classics, Use from Builder and Top/Bottom headings containing only provider names. Metacritic user and Rotten Tomatoes - audience/critic overrides live only in the report presentation; canonical dimension names, provider labels/identifiers and talent-role constants remain unchanged. The recurring role alone is lowercased and retains its strong element. Dynamic title/name/date templates retain their exact inserted values.

Scope boundary: canonical full score labels (such as IMDb Rating and Metacritic Critic Score) and formula/value labels in the Detail score summary were excluded from the original heading audit and are not ordinary action copy. They remain unchanged in this pass; future editorial treatment of these subordinate labels must preserve canonical identities and is outside this heading/action unification. Old inactive source listed in the inventory remains inactive and does not add audit occurrences.

STYLE.md now owns the permanent casing rule and uses the final UI examples, including Production countries. TESTING.md documents the focused fixture-only regression coverage; README action references and architecture/data report references match the displayed copy; the integration overview names the actual Seen destination. The inventory is historical evidence, not an instruction to apply its former classifications mechanically.
